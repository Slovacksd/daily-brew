# daily-brew
A front-end template for a coffee business by 'Alice' and 'Bob' utilizing a stack -> [Node.JS, React, Typescript, and TailwindCSS].

Simply navigate to source or '/src' and use 'npm run dev' to host the daily brew website locally.

# Design Decisions
The Daily Brew features a navigation bar, a cart for selected items, a basic payment processing system with regex checking;
and features blur effects enriched with TailwindCSS.

# motivation
The motivation for this project was to use Agile methodologies while iterating upon the language accessibility features,
the accessibility of navigation, and to promote an appealing UI for the prospective business client that this
website was built for; a famously overused alias of 'Alice' and 'Bob'.
